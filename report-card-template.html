A free report card template for Google Sheets

Here is a real template you can use without installing anything: the columns, the formulas that compute a weighted final and a letter, and a CSV you can import today. No sign-up, no add-on, no email wall.

Download the CSV template

The CSV is plain data — the formulas below go into your sheet alongside it, because a CSV file can't carry them.

The columns

One row per student. A name column, one column per assignment in each category, and a pair of columns for a points-based exam (earned, then possible). Empty cells are "not scored"; the word excused is "not scored, and marked excused"; a 0 is a real zero.

The formulas

The columns are A Student, B–D homework, E–F quizzes, G exam earned and H exam possible. The formulas keep the category averages in helper cells I, J and K, then the final in L and the letter in M.

1. Category averages (helper cells I, J, K)

Homework and quizzes are percentages, so a plain average works — AVERAGE already skips empty cells and the word excused. Exams are points, so average them as total earned ÷ total possible:

# I2 — homework average (columns B:D)
=IFERROR(AVERAGE(B2:D2), "")

# J2 — quiz average (columns E:F)
=IFERROR(AVERAGE(E2:F2), "")

# K2 — exam as a percentage (G earned ÷ H possible)
=IFERROR(100*SUM(G2:G2)/SUM(H2:H2), "")

2. The weighted final (helper cell L)

Weight the three category averages, then divide by the sum of the weights you entered, so 20/30/50 and 2/3/5 both work:

# L2 — weighted final — weights 20 / 30 / 50
=IFERROR(ROUND((I2*20 + J2*30 + K2*50) / SUM(20,30,50), 2), "")

3. The letter band (helper cell M)

# M2 — letter for the final grade in L2
=IFS(L2>=90,"A",L2>=80,"B",L2>=70,"C",L2>=60,"D",L2>=0,"F")

The worked example

Here is what those formulas return on the CSV above, with the arithmetic shown. These are the numbers the formulas produce, rounded to two decimals — the same numbers Gradewright's engine returns for the same rows:

Avery, step by step: homework (90 + 80 + 100) ÷ 3 = 90.00; quizzes (70 + 85) ÷ 2 = 77.50; exam 88 ÷ 100 = 88.00; final (90.00 × 20 + 77.50 × 30 + 88.00 × 50) ÷ 100 = (1800 + 2325 + 4400) ÷ 100 = 85.25.

Jordan's excused homework is left out of the average: (88 + 92) ÷ 2 = 90.00. Maria's blank homework is left out too: (79 + 81) ÷ 2 = 80.00, and her exam is 42 ÷ 50 = 84.00.

Three ways this template goes wrong

1. A new student row has no formulas

Copy the formulas down for every student, and re-copy when a new student arrives mid-term. A missed row is a blank final grade that looks intentional until a parent asks.

2. An empty cell that should be a zero

AVERAGE skips empties, so a student with three 90s and a missing homework averages 90.00, while three 90s and a typed 0 average 67.50. The template can't tell which you meant — you have to type the 0. See excused vs blank vs zero.

3. Inserting a column shifts the averages

The category-average formulas name columns B through H by hand. Insert a column and they silently point at the wrong scores, while the final still reads the helper cells I, J and K. That's the single biggest reason people abandon a spreadsheet gradebook.

When this template is the better answer. One class, one set of weights, no points-based mixing, and you don't need printed cards — this template is all you need. Gradewright is the better tool the moment you have several classes, per-category drop-lowest rules, or report cards to produce: it re-detects your columns on every compute instead of trusting column letters.
